# QueridoDiario

Aplicación web para crear y guardar entradas personales en un diario.

Permite registrarse e iniciar sesión, crear entradas con fecha y notas, verlas, editarlas, eliminarlas y buscar en su contenido. Cada usuario accede únicamente a sus propias entradas.

La aplicación está construida con Flask y utiliza MySQL para almacenar usuarios y entradas.
